# IronWorks Gym — Project Details

## Concept / demo notice
IronWorks Gym is a **fictional business**. This is a concept/demo project built by SPManchester to
demonstrate Web Design & Development capability. Sample prices, reviews and figures are illustrative.

## Business problem (market need)
Independent gyms run their business from a noticeboard: timetable screenshots on Instagram, pricing by DM, and joining via a paper form at the desk. Every friction point sends ready-to-join members to the budget chains with slick apps.

## Solution built
A data-driven gym website: the full timetable renders from structured class data with day and category filters (the same pattern as a real booking system), honest membership tiers, and an online joining flow that confirms instantly — indie character, chain-level convenience.

## Interactive feature (working demo)
Data-driven class timetable (18 classes) with day & category filters, membership plans and an online joining flow with instant confirmation.

## Pitch in one line
Indie gyms run on Instagram screenshots and paper forms. This site gives them chain-level convenience: a live timetable and 2-minute online joining.

## Features
- Responsive, mobile-first design with a modern 2026-standard look (sticky nav, gradient hero, card layouts)
- Problem → Solution storytelling section, written to pitch the service to a client
- Data-driven class timetable (18 classes) with day & category filters, membership plans and an online joining flow with instant confirmation.
- FAQ section and sample testimonials (clearly labelled as sample content)
- SEO-ready: semantic HTML, meta description, descriptive headings
- Zero dependencies — opens and hosts anywhere

## Tech stack
HTML5 · CSS3 (custom properties, grid/flex, media queries) · Vanilla JavaScript

## How to run / host
Open `index.html` directly, or deploy the folder to GitHub Pages / Netlify / any static host.
